# TramAI native sovereign evidence

The application exposes the publish-safe TramAI-native runtime posture at:

```text
GET /governance/sovereign-evidence
```

The response is `SovereignEvidencePackV1`, generated by the existing single
`SovereignTramai` composition. It contains the configured model allowlist,
provider allowlist, provider trust zones, artifact-verification settings and
optional evidence sections supported by the pinned TramAI revision.

Deterministic verification:

```text
./gradlew :app:test --no-daemon --console=plain
```

`SovereignEvidencePackIT` verifies the endpoint, the LOCAL/EU_CLOUD/GLOBAL_CLOUD
provider-zone declarations, and the absence of prompts, filesystem paths,
API-key fields and secret fields. The pack is configuration/runtime evidence;
behavioral routing and counter evidence remains indexed by task-008.

Pinned TramAI revision: `852c89ba265466c54217557d2dc5db83760691c`.

## Limitations

The current Spring composition does not configure a local model artifact
manifest or `ModelArtifactVerifier`, so no local Nemotron artifact hash is
claimed. The existing application telemetry intentionally records the
application's proposed route; TramAI operation spans remain the runtime model,
provider and attempt evidence. Removing those proposal fields would reduce
visibility into the deliberate misroute proof, so telemetry duplication was
not changed in this task.
